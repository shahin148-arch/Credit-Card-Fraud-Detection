"# Credit-Card-Fraud-Detection" 
A machine learning project that detects fraudulent credit card transactions using Python. The model helps in identifying suspicious activity and preventing financial loss.

#Technologies Used

This project was developed using Python and the following libraries:

NumPy – for numerical computations

Pandas – for data manipulation and analysis

Matplotlib / Seaborn – for data visualization

Scikit-learn – for machine learning models and evaluation
